---
title: Marketplaces
description: Add, update and remove the plugin marketplaces that Codex knows about.
---

A marketplace is a list of plugins that you can install. Codex keeps your marketplaces in your global configuration, and all your projects share them. So Codexed shows marketplaces only in the global view. In a project, **Marketplaces** asks you to open the global view.

## Add a marketplace

Under **Add a marketplace**, enter the source:

- A GitHub repository, as `owner/repo`.
- A git URL.
- A folder on this computer.

For a git source, you can also enter a branch or tag. Without one, Codex uses the default branch. Then choose **Add marketplace**. Codex downloads the marketplace, which can take a moment.

## Update and remove

**Your marketplaces** lists each marketplace with its number of plugins and the folder where Codex keeps it.

- **Update** gets the latest version of one marketplace. **Update all**, at the top right, updates all of them.
- **Remove** removes the marketplace from Codex. Codexed asks first.

If a marketplace does not load, Codexed shows the error of Codex above the list.
