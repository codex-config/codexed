A plugin adds to Codex, for example with skills or MCP servers. Plugins come from [marketplaces](/docs/marketplaces).

Plugins apply to every project, so you manage them in the global view. In a project, **Plugins** asks you to open the global view.

## Which plugins Codexed shows

Codexed asks Codex for the plugins of every marketplace that Codex knows. It groups them by marketplace, with their version and a short description. Installed plugins have the **Installed** label. Use the filter to find a plugin by its name or description.

If you have no marketplace with plugins yet, **Plugins** offers to add one.

## Install and uninstall

Choose **Install** or **Uninstall** next to a plugin. Codex does the work, and it may need to download the plugin first. If Codex cannot install a plugin, Codexed shows its message.

The sidebar shows the number of installed plugins next to **Plugins**.
